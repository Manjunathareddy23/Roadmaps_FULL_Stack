    How to learn every topic

    Use the same four steps for each checkbox below.

    1. Read the official docs

      Start with the matching page on react.dev, MDN or the library's own site. Keep it to about 15 minutes.

    2. Code along

      Type the example in a scratch project. Break it on purpose and read the error messages.

    3. Rebuild from memory

      Close the tutorial and recreate it. Whatever you cannot rebuild is what you have not learned yet.

    4. Extend it

      Add a feature the tutorial did not have, and handle loading, error and empty states.

    Gate rule: do not start the next phase until the current phase's project is built, deployed and has a README.

    Mistakes that slow people down

    Check yourself against these every few weeks.

    • Learning many libraries at once. Master one tool per category before you compare alternatives.
    • Watching without building. Pause the video, type it yourself, then rebuild it from memory.
    • Skipping JavaScript fundamentals. Closures, mutation and async cause most confusing React bugs.
    • Reaching for useEffect first. Derived values and event handlers cover most cases.
    • Memoizing everything. Measure with the Profiler before adding useMemo or useCallback.
    • Only cloning tutorials. Add your own features and handle the edge cases the tutorial skipped.
    • Never deploying. Put every project live with a README and a short architecture note.
